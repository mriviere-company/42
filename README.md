# École 42 Paris — projects (2014–2017)

*[Version française plus bas](#français)*

My projects from [École 42](https://42.fr/) in Paris: a school with no teachers and no
lectures, where everything is learned through projects and peer review. Most projects are
in **C on macOS**, with the school's MiniLibX graphics library, under the school's strict
coding standard (the "Norm"). The code is kept as written at the time.

## C projects

| Project | What it is | Skills |
|---|---|---|
| [`libft`](c/libft) | My own C library: a re-implementation of part of the standard library, plus linked lists | Memory management, pointers |
| [`printf`](c/printf) | `ft_printf`, a re-implementation of `printf` | Variadic functions, format parsing |
| [`gnl`](c/gnl) | `get_next_line`: read a file descriptor line by line | Buffers, file I/O |
| [`fdf`](c/fdf) | Wireframe 3D rendering of a height map, isometric projection, Bresenham's line algorithm | Geometry, graphics |
| [`fractol`](c/fractol) | Interactive fractal explorer: Mandelbrot, Julia, Burning Ship, with zoom | Complex numbers, pixel rendering |
| [`wolf3d`](c/wolf3d) | A Wolfenstein 3D-style engine using raycasting | Raycasting, camera, rendering loop |
| [`rt`](c/rt) | A ray tracer with XML scenes (reflection, refraction, several objects) — **group project of four**; most of its code was written by my teammates | Teamwork, ray tracing |

[`exam`](exam) holds exam exercises (string handling, linked lists, sorting).

## PHP

[`php`](php) holds the PHP "piscine" (an intensive two-week bootcamp, days `j00`–`j04`),
MySQL exercises, and an e-commerce website built in a pair (catalog, categories, basket,
accounts, admin). It is where I turned to web development, which became my career.

# École 42 Paris — projets (2014–2017)

Mes projets de l'[École 42](https://42.fr/) à Paris : une école sans professeurs ni cours,
où tout s'apprend par projets et par évaluation entre pairs. La plupart des projets sont en
**C sous macOS**, avec la bibliothèque graphique MiniLibX de l'école, et respectent sa norme
de code stricte (la « Norme »). Le code est conservé tel qu'écrit à l'époque.

## Projets en C

| Projet | De quoi il s'agit | Compétences |
|---|---|---|
| [`libft`](c/libft) | Ma propre bibliothèque C : une partie de la bibliothèque standard réécrite, plus des listes chaînées | Gestion mémoire, pointeurs |
| [`printf`](c/printf) | `ft_printf`, une réécriture de `printf` | Fonctions variadiques, analyse de format |
| [`gnl`](c/gnl) | `get_next_line` : lire un descripteur de fichier ligne par ligne | Tampons, entrées-sorties |
| [`fdf`](c/fdf) | Rendu fil de fer 3D d'une carte d'altitudes, projection isométrique, algorithme de Bresenham | Géométrie, graphisme |
| [`fractol`](c/fractol) | Explorateur de fractales interactif : Mandelbrot, Julia, Burning Ship, avec zoom | Nombres complexes, rendu pixel |
| [`wolf3d`](c/wolf3d) | Un moteur façon Wolfenstein 3D par lancer de rayons (raycasting) | Raycasting, caméra, boucle de rendu |
| [`rt`](c/rt) | Un ray tracer avec scènes XML (réflexion, réfraction, plusieurs objets) — **projet de groupe à quatre** ; l'essentiel du code a été écrit par mes coéquipiers | Travail d'équipe, lancer de rayons |

[`exam`](exam) contient des exercices d'examen (chaînes, listes chaînées, tris).

## PHP

[`php`](php) contient la piscine PHP (deux semaines intensives, jours `j00` à `j04`), des
exercices MySQL et un site e-commerce réalisé en binôme (catalogue, catégories, panier,
comptes, administration). C'est là que je me suis tourné vers le développement web, devenu
mon métier.
